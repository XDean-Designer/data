# data · 数据导入功能原型

剑琅联盟商户端「开店入驻与数据迁移」高保真交互原型。

## 在线预览

- 原型入口：https://xdean-designer.github.io/data/
- PRD：https://xdean-designer.github.io/data/PRD-开店入驻与数据迁移.html

本地打开：用静态服务器打开本目录（勿用 `file://`），例如：

```bash
npx --yes http-server . -p 8765 -c-1 --cors
```

然后访问 `http://127.0.0.1:8765/`。

## 目录说明

| 路径 | 说明 |
|------|------|
| `index.html` | 原型主入口（390 画布） |
| `app.js` / `*.css` | 交互与样式 |
| `assets/` | 图片与图标 |
| `excel模板/` | 官方 Excel 导入模板样品 |
| `PRD-开店入驻与数据迁移.html` | 产品需求预览 |
| `对标-登录入驻体验优化.html` | 对标研究 |
